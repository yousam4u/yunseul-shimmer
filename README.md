## 보는 방법

| 조작 | 동작 |
|---|---|
| 자동재생 | 음악과 함께 3분 8초 동안 자동으로 넘어갑니다 |
| 음악 | 사운드트랙만 따로 켜고 끕니다. 재생을 멈추면 페이지도 함께 멈춥니다 |
| ‹ › · 방향키 · 스와이프 | 직접 넘기기 (자동재생 중에는 음악도 해당 지점으로 같이 이동합니다) |
| 전체화면 | 몰입해서 보기 |

자동재생은 음악의 흐름에 맞춰 설계했습니다. 도입의 정적에서 표지가 머물고,
음악이 가장 낮게 가라앉는 지점에서 「빛의 비상」이 열리며,
최고조에서 에필로그의 문장이 도착한 뒤 잔향과 함께 책이 닫힙니다.

## 기술 메모

- 단일 HTML 파일 하나로 완결됩니다. 모든 이미지와 사운드트랙이 내장되어 있어 인터넷 없이도 열립니다.
- CSS 3D 변환으로 책장 넘김을 구현했고, 페이지 전환은 오디오 재생 위치를 기준으로 동기화됩니다.
- 브라우저가 소리 재생을 막는 경우에도 자동 넘김은 그대로 진행되며, 화면을 한 번 클릭하면 음악이 이어서 시작됩니다.
- 용량이 약 8MB라 첫 로딩에 잠시 시간이 걸릴 수 있습니다.
